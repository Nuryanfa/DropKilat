## Tests added
- `cmd/dropkilat/signal_unix_test.go`:
  - `TestGracefulShutdown_CompletesInFlightRequestOnSIGTERM`: matches the exact NFR-8 test identifier in `docs/test-plan.md` §4 (`cmd/dropkilat`).
  - `TestMainProcessSIGTERMExitsZero`: launches `main()` in a real Unix subprocess with valid `DK_*` configuration, verifies `GET /healthz` returns `200`, sends `syscall.SIGTERM`, and asserts clean exit code `0`.
- `internal/platform/config/config_test.go`:
  - `TestLoad_QAEdgeCasesAndSecretNonLeakage`: tests 31-byte and 33-byte base64 keys, URL-safe base64 rejection, `DK_BASE_URL` with embedded userinfo credentials, `DK_DATABASE_URL` / `DK_MIGRATE_DATABASE_URL` with invalid scheme/empty path and embedded passwords (verifying passwords never leak via `url.Parse` errors), port `0` and `65536` rejection, non-E.164 `DK_WA_BUSINESS_NUMBER` when `DK_FEATURE_WA_SEND=true`, trailing-comma rejection in `DK_OWNER_PHONES`, and whitespace trimming around valid `DK_OWNER_PHONES` entries.
- `internal/platform/clock/clocktest/fake_test.go`:
  - Compile-time interface checks `var _ clock.Clock = (*Fake)(nil)` and `var _ clock.Clock = clock.Real{}`.
