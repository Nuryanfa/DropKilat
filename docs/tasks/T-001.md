# T-001 — Build the clickable prototype for seller interviews

## Goal
A seller can open one link on their phone and, in 30 seconds, feel how a drop works: countdown, Ambil, 15-minute hold, and stock moving to the next buyer when someone does not pay.

## Context
- Screens and copy: `docs/design.md` §3 (B1, B2, B3, B6) and §2 tokens.
- Flow: `docs/app-flow.md` §4 and §6.

## Scope
- In: static `prototype/index.html` + `prototype/app.js` + `prototype/style.css`; fake data; all state in memory.
- Out: backend, real payments, real WhatsApp, build tools (no npm required to open it).

## Interfaces
Prototype controls (visible in a small "Mode demo" panel at the bottom):
1. "Buka drop sekarang" — skip the countdown.
2. "Simulasikan 30 pembeli rebutan" — stock drops quickly from 10 to 0; the viewer is placed in waitlist #3 if they did not claim.
3. "Simulasikan pembeli pertama tidak bayar" — one hold expires; stock goes to waitlist #1; show a mock WhatsApp bubble "Giliranmu! Bayar dalam 15 menit".
4. "Percepat timer" — hold timer runs 30× faster.

## Acceptance criteria
1. Works on a 360 px wide phone screen and on desktop.
2. Opens from a static host or as a local file; no network requests after load except fonts (fallback to system fonts offline).
3. Copy in Bahasa Indonesia, exactly the strings in `docs/design.md` where given.
4. Timer, stock counter and waitlist position update without page reload.
5. No console errors; total size < 200 KB excluding fonts.

## Test expectations
- Gemini runs T-002 (accessibility, viewport, copy) on this PR.

## Risks and notes
The prototype must never look like it takes real money: the QRIS is a placeholder labelled "Contoh".
