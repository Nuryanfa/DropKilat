## Tests added
- `tests/prototype/qa_test.py`: Automated Playwright QA suite covering:
  - WCAG 2.1 AA color contrast calculation (`>= 4.5:1`) for all visible text nodes across `B1-before`, `B2-live`, `B3-hold`, `B3-urgent`, `B4-confirmation`, `B6-waiting`, and `B7-expired`.
  - Touch target bounding-box verification (`>= 44×44 px`) for all buttons across every screen state on a `360×800` viewport.
  - Horizontal overflow check (`scrollWidth <= innerWidth`) across every state at `360 px`.
  - Exact Bahasa Indonesia copy assertions against `docs/design.md` §3 & §6 and `docs/tasks/T-001.md`.
  - `MutationObserver` verification on `#timer-announcement` confirming screen-reader announcements fire once per minute boundary and never every second.
  - Keyboard `Tab` + `Enter` verification for `.skip` link and `aria-pressed` state on `#speed`.
