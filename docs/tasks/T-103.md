# T-103 — platform/httpx: router, middleware, problem+json, rate limiter

## Goal
One HTTP stack with the safety features every handler needs, so feature cards only write handlers.

## Context
- `docs/backend.md` §3 (routes, JSON vs HTML), §4 (problem types), §9 (logging, masking).
- `docs/trd.md` §7 (rate limits, headers, webhooks body limit), §8 (logs, metrics).

## Scope
- In: `internal/platform/httpx`:
  - router on `net/http` patterns;
  - middleware chain: request id, structured access log, recover, security headers, body size limit, rate limiter;
  - problem+json writer and domain-error mapping;
  - phone/PII masking helper for `slog`;
  - Prometheus HTTP latency histogram.
- Out: CSRF and sessions (T-303), SSE (T-302), concrete domain errors (their cards register them).

## Interfaces
```go
type Problem struct {
    Type   string            `json:"type"`   // slug from backend.md §4
    Title  string            `json:"title"`
    Status int               `json:"status"`
    Detail string            `json:"detail,omitempty"`
    Errors []FieldError      `json:"errors,omitempty"`
}
func WriteProblem(w http.ResponseWriter, r *http.Request, p Problem)
// Register maps a typed domain error (errors.Is/As) to a problem type.
func Register(target error, typ string, status int)
func WriteError(w http.ResponseWriter, r *http.Request, err error) // unknown → 500 "internal", detail hidden

type Limiter interface{ Allow(key string) (ok bool, retryAfter time.Duration) }
func NewTokenBucket(rate float64, burst int, clk clock.Clock) Limiter // in-memory, evicts idle keys
func RateLimit(l Limiter, key func(*http.Request) string) func(http.Handler) http.Handler

func MaskPhone(e164 string) string // "+6281234567789" → "+62812****789"
```
`rate float64` is allowed here: it is a rate, not money.

Security headers: CSP `default-src 'self'; img-src 'self' data:; frame-ancestors 'none'` (fonts self-hosted), HSTS (prod only), `X-Content-Type-Options: nosniff`, `Referrer-Policy: strict-origin-when-cross-origin`.

## Acceptance criteria
1. Every response carries `X-Request-Id` (generated, or taken from the request if it matches `^[A-Za-z0-9-]{1,64}$`).
2. A panicking handler → 500 problem+json; the stack trace is logged, never returned.
3. `rate-limited` → 429 with `Retry-After` in whole seconds.
4. Body over the configured limit → 413 problem.
5. All ten problem types in `docs/backend.md` §4 have a test that maps a sample error to the right status.
6. The access log line has `request_id`, method, route pattern (not the raw path with IDs), status and duration. A test asserts that no query string and no phone number appear in it.

## Test expectations
- Unit: limiter with `clocktest.Fake` (refill, burst, eviction); problem mapping; masking; headers.

## Risks and notes
- The limiter is in-memory because we run one binary (ADR 0001). Keys must be bounded: evict keys idle for 10 minutes.
- Behind Caddy, the client IP comes from `X-Forwarded-For`. Trust it only when `DK_ENV=prod` and the peer is the proxy; document the setting in `docs/backend.md` §8 if you add one.
