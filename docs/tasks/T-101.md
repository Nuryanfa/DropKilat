# T-101 — Go module, main with graceful shutdown, config and clock

## Goal
`make run` starts a `dropkilat` binary that serves `/healthz`, refuses to start on bad configuration, and stops cleanly on SIGTERM. Every later package gets its configuration and time from here.

## Context
- `docs/backend.md` §8 (all `DK_*` variables) and §9 (conventions).
- `docs/trd.md` §2 (stack), §9 (configuration).
- ADR 0005 "Time": domain code and SQL take time from `clock.Clock`.
- P1 may start before Gate A (PO decision 2026-11-11).

## Scope
- In: `go.mod` (module `github.com/Nuryanfa/DropKilat`, Go 1.27), `cmd/dropkilat/main.go`, `internal/platform/config`, `internal/platform/clock`, `/healthz`, `.golangci.yml`.
- Out: database (T-102), middleware, router details and rate limits (T-103), CI (T-104).

## Interfaces

```go
// internal/platform/clock

// internal/platform/clock/clocktest
type Fake struct{ /* mutex-protected */ }
func NewFake(t time.Time) *Fake

func (f *Fake) Advance(d time.Duration)
```
`main`: load config → build dependencies → `http.Server` with `ReadHeaderTimeout` 5 s → on SIGINT/SIGTERM call `Shutdown` with a 20 s deadline. Later workers register a `Run(ctx) error` and are stopped through the same context.

## Acceptance criteria
1. `make run` with `.env` copied from `.env.example` (keys filled) serves `GET /healthz` → `200 {"status":"ok"}`.
2. A missing required variable or a key that is not 32 bytes → exit code 1. The message names every bad variable and never prints a value.
3. Xendit and WhatsApp variables are required only when their feature flag is true.
4. SIGTERM during an in-flight request: the request completes, then the process exits 0.
5. `clocktest.Fake` is safe for concurrent use (`go test -race`).
6. `.golangci.yml` enables at least `govet`, `staticcheck`, `errcheck`, `gosec`, and `forbidigo` with two rules: `time.Now` banned outside `internal/platform/clock`, and `float64` / `float32` banned in `internal/order`, `internal/payment` and `internal/billing`.

## Test expectations
- Unit: `config.Load` table tests (missing, malformed base64, wrong key length, feature flags on/off, owner phone not E.164).
- Unit: `clocktest.Fake` advance and concurrency.
- Integration: start the binary in a test, send SIGTERM, assert exit 0 (may use `os/exec`).

## Risks and notes
- Never log config values. Log only the names of the variables that are set.
- No third-party config library; the standard library is enough.
