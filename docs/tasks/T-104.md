# T-104 — CI pipeline with real RLS role, lint, vuln scan and image build

## Goal
Every PR is checked the same way: lint, tests against real migrations **with the app role**, reversible migrations, known vulnerabilities, prototype tests, and an image that builds.

## Context
- Current `.github/workflows/ci.yml`. Its Postgres service never runs `deploy/init-db.sql`, so `dropkilat_app` does not exist and the grant block in migration 000001 is skipped. RLS is never exercised as the app role in CI.
- `Makefile`, `scripts/migrate-check.sh`, `tests/prototype/*.py`.

## Scope
- In:
  - `.github/workflows/ci.yml`, `Makefile`, `scripts/` (allowed for this card; normally the TL's area per `docs/agents/worktrees.md`);
  - `Dockerfile` (multi-stage, distroless static, non-root).
- Out: deploy (T-703).

## Interfaces
CI jobs (run in parallel where possible):

| Job | Steps |
| --- | --- |
| `lint` | `golangci-lint` (pinned action and version, config from T-101) |
| `test` | Postgres 17 service → `psql -f deploy/init-db.sql` → `scripts/migrate-check.sh` → `go test -race ./...` |
| `vuln` | `govulncheck ./...` (pinned version) |
| `prototype` | Python 3.12 + Playwright (pinned) → `tests/prototype/smoke.py` and `qa_test.py` |
| `image` | `docker build`; fail if the image is ≥ 40 MB |

## Acceptance criteria
1. Every tool and action is pinned to an exact version: no `@latest`, actions pinned by version tag or SHA.
2. In the `test` job, a step asserts that role `dropkilat_app` exists and has no `UPDATE` on `audit_log`.
3. The Go steps no longer skip when `go.mod` is missing (`go.mod` exists after T-101).
4. Pipeline is green on this PR; total wall time under 8 minutes with module and build caches.
5. Image runs as non-root and is < 40 MB.

## Test expectations
- The pipeline itself. Push one deliberately failing commit (lint error) to prove the job goes red, then revert it, and mention it in the PR.

## Risks and notes
- Keep secrets out of CI; none are needed for this card.
- `init-db.sql` has a development password; that is fine for CI and must not be reused in production (T-703).
